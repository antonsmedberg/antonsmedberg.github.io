Om mig

Native mobile med systembakgrund.

Jag fokuserar på native iOS eftersom det är där min starkaste produktionserfarenhet och bästa arbete finns. Java backend och Android/Kotlin hjälper mig att förstå API:er, dataflöden och angränsande plattformar utan att behandla varje problem som ett UI-problem.

Jag söker en roll som iOS- eller mobilutvecklare där jag kan bidra i produktionskod, lära av erfarna utvecklare och ta ansvar för successivt svårare problem.
