Om mig

Mobil först. Systemmedveten.

Jag fokuserar på native iOS eftersom det är där min starkaste produktionserfarenhet och bästa arbete finns. Java backend och Android/Kotlin är värdefullt på ett annat sätt: det gör det lättare att förstå API:er, dataflöden och angränsande plattformar utan att behandla varje problem som ett SwiftUI-problem.

Jag söker en roll som iOS- eller mobilutvecklare där jag kan bidra i produktionskod, fortsätta lära av erfarna utvecklare och ta ansvar för successivt svårare problem.
