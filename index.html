About

Junior by title, production-trained by practice.

My iOS work started at Malmö Yrkeshögskola and got serious at Axis Communications, where I spent five months inside an established production codebase — not a sandbox. I shipped SwiftUI improvements, migrated asynchronous flows to async/await under strict Swift Concurrency, worked on live-video controls, and added Datadog and OpenTelemetry instrumentation so failures could actually be traced.

Since graduating in May 2026 I've been building independently: an on-device captioning app, a Metal Gaussian-splat renderer, and an open-source Swift package for GPU-backed SwiftUI components. The common thread is doing the heavy work on the device — no servers, no accounts, no data leaving the phone.

I also carry a Java backend degree (Spring Boot, JPA, SQL) and a year of Android/Kotlin, which means I can read the other side of an API instead of guessing at it.

Selected work

Four things I built, and what each one taught me.

Status is stated plainly — shipped, in development, or open source. No mockups pretending to be products.

Subtl

iOS app · one-time purchase

In development

Privacy-first captioning for short-form video. Transcription runs entirely on-device through Apple's SpeechAnalyzer — no upload, no account. Five caption styles render identically in preview and export, enforced by a single CaptionStyle source of truth and a Core Animation compositor.

The interesting problem was preview/export parity: what you see while scrubbing has to be pixel-identical to what AVFoundation writes to the file.

Swift 6SpeechAnalyzer AVFoundationActors StoreKit 2

Prism Spatial

iOS app · 3D viewer

In development

A 3D Gaussian-splat viewer. Imports PLY captures from tools like Scaniverse and renders them with a hand-written Metal splat renderer using EWA covariance projection, then applies tilt-shift and colour grading to make the scene read as a miniature.

I rescoped it after finding Apple's RealityKit splat component was render-only in beta — knowing when a framework can't carry you is part of the job.

MetalARKit / LiDAR RealityKitSwiftData

MetalVisualKit

Swift package · MIT

Open source

Metal-backed SwiftUI components: a GPU particle progress loader driven by a compute shader, and an ARKit LiDAR point-cloud renderer that unprojects roughly 49,000 depth samples per frame on the GPU.

Published as a proper SPM package — DocC documentation, unit tests, an example app and CI — because a library nobody can integrate isn't a library.
