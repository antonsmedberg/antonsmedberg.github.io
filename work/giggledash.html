Giggle Dash

In development

A landscape chase game for iPhone and iPad, built with SwiftUI and SpriteKit. Run through seven painted chapters while Mom or Grandma chases you and throws things, and reach the monster-mouth portal at the end of each chapter.

Role
Developer
Stack
SwiftUI, SpriteKit, AVFAudio, GameController

What it is

Jump, slide and stomp past logs, swing rings, gremlins, mimic chests and couch potatoes. The chasers have moods and speech bubbles. They wind up before throws, laugh when you get hit and get distracted. When you are down to one heart, they turn into monsters.

There are four power-ups, a combo multiplier up to x5, missions and a seeded Daily Dash with a streak bonus. In the Wardrobe you can import your own character. Every action fires on touch-down, and the game plays with touch, a keyboard or a game controller. It supports Reduce Motion and has VoiceOver labels.

The rules do not know the renderer exists

The simulation depends only on Foundation. SpriteKit just draws what it reports.

Physics, the course generator, the chase, collisions, scoring, missions and progress all live in Core. The simulation runs in fixed sub-steps and emits GameEvents, and the renderer reacts to them. That split means the game logic can be tested on any machine with a Swift 6 toolchain, including Linux.

A bot that checks fairness

A course generator can build a pattern nobody can clear. So the tests include a bot that plays every generated pattern with human reaction limits, and a pattern it cannot clear fails the tests.

Rebuilt from what was left

This project is a reconstruction. The original source folder went missing, so the code was rebuilt from the art, the audio and a previous app build. The source art and audio stay unchanged in the repository. Two deterministic scripts turn them into the sprite atlases, backgrounds and sound effects the app bundles.

Current state

In development. It uses only Apple frameworks and builds in Swift 6 language mode with complete concurrency checking. The repository is private.
