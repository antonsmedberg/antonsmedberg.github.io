Subtl

Privacy-first captioning for short-form video. Transcription runs entirely on-device — no upload, no account, no data leaving the phone.

What it does

Subtl captions short-form video entirely on the device using Apple's SpeechAnalyzer and SpeechTranscriber. No server-side processing, no account creation, no data ever leaving the phone. Five caption styles render identically in preview and export.

Engineering approach

The hardest problem was preview/export parity: what you see while scrubbing has to be pixel-identical to what AVFoundation writes to the file. The solution is a single CaptionStyle model that both the preview compositor and the export session read from, enforced by a Core Animation compositor.

The app is built on Swift 6 strict concurrency. Speech recognition, file I/O and caption rendering are isolated behind actors, with the view layer observing through @MainActor view models. StoreKit 2 handles the one-time purchase — no subscriptions, no ads.
