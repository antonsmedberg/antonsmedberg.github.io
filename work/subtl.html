Subtl

Privacy-first captioning for short-form video, built around on-device transcription and a shared rendering model for preview and export.

The product problem

A caption editor has two rendering paths that can drift apart: the interactive preview and the exported video. If style, timing or positioning are implemented twice, the user can spend time refining a result that changes after export.

Engineering approach

  • Use a shared caption-style model as the source of truth for preview and export.
  • Keep transcription work isolated with Swift concurrency instead of tying long-running speech work directly to view state.
  • Use AVFoundation and Core Animation for deterministic export rather than depending on the live SwiftUI hierarchy.
  • Keep transcription on-device and avoid requiring an account or upload pipeline.

Current state

Subtl is still in development, so I describe the architecture and current constraints without presenting it as a shipped App Store product.
