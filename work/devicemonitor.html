DeviceMonitor

Network-device monitoring app built with SwiftUI, SwiftData, and strict Swift 6 concurrency — where I worked out how to keep a data layer safe across actor boundaries.

What it does

DeviceMonitor is an iOS prototype for monitoring network devices. It shows a dashboard with online/offline status, status history, filtering by name or IP, and a detail view for each device. The app intentionally uses mock data — it demonstrates architecture, not production networking.

Engineering approach

The project is built around three boundaries:

  • Service layer — mock monitor that produces device snapshots, isolated behind a protocol so it could be replaced with real network scanning.
  • Storage layer — SwiftData persistence with actor-safe fetch and save operations.
  • View layer — SwiftUI views that observe a view model, which coordinates the other two layers.

Six unit tests cover the core logic: filtering, counter correctness, stale device removal, user-added device preservation, status-history transition rules and IP-based identity matching when service IDs change.
