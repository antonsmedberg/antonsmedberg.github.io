MetalVisualKit

Metal-backed SwiftUI components packaged as a reusable library — a GPU particle loader and an ARKit LiDAR point-cloud renderer.

What it does

MetalVisualKit is a Swift Package that explores GPU-first UI on iOS. SwiftUI owns the view lifecycle while Metal handles the per-particle and per-point work. It contains two main components:

  • Particle progress loader — a 1,400+ particle system driven by a compute shader, rendered as a SwiftUI view with full control over timing, color and density.
  • LiDAR point-cloud renderer — unprojects roughly 49,000 depth samples per frame from ARKit's scene reconstruction and renders them entirely on the GPU.

Engineering approach

The package is built to be used, not just demonstrated. It ships with DocC documentation, a 15-test suite covering the compute pipeline, an example app and CI that builds the package, the tests and the example on every push.

A design decision I am glad I made: keeping the public API as SwiftUI views, not Metal objects. A developer using this package should not need to understand compute encoders — just drop in a view and configure it.
